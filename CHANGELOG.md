# Changelog

## 0.2.0

### Minor Changes

- Added Archive Review to the Command Palette. It removes every card and thread at once, after a confirmation, and keeps the old log as `review-notes.<date and time>.jsonl` in the git directory

## 0.1.1

### Patch Changes

- New icon with a transparent background
- Added the AI category
- Added links to the Marketplace and Open VSX pages in the README

## 0.1.0

- First release
- Questions and answers on any line of the working-tree diff, on the new or the old side
- Notifications when the agent comments or replies
- Numbered cards in reading order, with Next Card, Previous Card and Next Unread Card, read tracking, a card list in the Source Control sidebar, file badges and a status bar item
- A bundled CLI for agents: `post`, `focus`, `list` and `archive`
- Works with VS Code 1.80 or later
